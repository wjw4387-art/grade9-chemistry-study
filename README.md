# 九年级上册化学自主学习工具

按人教版九年级上册新教材的七个单元组织。可任选课题学习、跳过已掌握内容、复习错题，并进行课题、单元和全册测试。

## 使用

打开[正式学习网站](https://grade9-chemistry-study.vercel.app/)，选择单元和课题即可学习。每课提供核心定义、通俗讲解、知识示意图、解题方法、例题和 16–18 道原创练习题。学习进度和错题保存在当前浏览器。

## 部署

这是无需构建的静态网站。将仓库导入 Vercel，Framework Preset 选 `Other`，Root Directory 保持 `./`，Build Command 留空，Output Directory 留空即可。

## 内容说明

教学内容根据九年级上册课程知识结构原创整理；练习题按初中阶段常见考试题型设计，非教材或练习册原题。示意图用于教学理解，尺寸与比例不代表真实装置或微粒。
