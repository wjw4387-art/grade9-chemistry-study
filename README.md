# 知学 · 自主学习空间

[进入学习网站](https://grade9-chemistry-study.vercel.app/)

自由选择想学的单元和知识点，按自己的节奏学习、复习与做题。

## 已开放课程

| 课程 | 范围 | 小课 | 原创练习 |
|---|---|---:|---:|
| 初中物理 | 八上、八下、九年级全一册，22章 | 93 | 1488 |
| 九年级化学 | 上下册，11单元 | 53 | 848 |

物理按截至2026年核验的人教版新教材目录编排，含12项跨学科实践。对应2024修订教材体系；2026是本项目的核验年份，不冒称存在独立“2026修订版”。各课程的说明页面提供版本与来源。

每课含核心定义、通俗解读、专题展开、例题、知识清单、易错提醒和可放大的原创图示。两门课程均为每课16题，每4题提升一级：基础理解、应用辨析、中考综合、拓展拔高。化学以广州中考为参照，最后两题保留更高迁移要求的设计；含单选、多选、填空、综合探究、操作排序与分类匹配。分级表示教学设计要求，尚未通过学生作答样本校准。

## 怎么使用

1. 进入课程中心，选择物理或化学，再选册次、章节和小课；也可搜索本学科知识点。
2. 阅读讲解和图示。已经掌握的课可以直接标记，也可以暂时跳过。
3. 选择本课练习或章节、综合测试。化学章节与综合测试每轮16题，四档各4题；物理章节24题、综合40题。答题卡可以任意跳题，作答自动保存。
4. 提交后先查看独立展示的正确答案，再看解题依据、分步解析与本课易错提醒；可跳转回相关知识点或例题，再返回原题。错题进入复习本，重做答对后移出。
5. 在“课程说明与学习记录”导出备份，换浏览器或设备时导入继续学习。

多选题在题干前使用醒目标识与完整选项要求，答题卡也标明“多选”；漏选、错选均不得分。

页面右上角可选择16、18、20、22或24px阅读字号：默认正文18px，导航15px、辅助信息14px，桌面正文宽度最多760px。界面文字随阅读偏好适度放大，化学、物理与课程中心共用此偏好。示意图支持放大，手机可横向查看较宽图表。

两门学科的进度、错题和未完成练习分别保存。学习记录只存于当前浏览器，没有账号或跨设备自动同步。填空与综合题使用规范答案集合匹配，请遵循题目要求的单位和格式；不支持任意同义长句的语义评分。

旧版化学练习中的已退役题目会归档保留原错题次数及未完成答卷，可随课程记录一起导出备份。

## 教材与内容

[人教社新版初中物理教材介绍](https://www.pep.com.cn/xw/zt/hd/12/xjcjs/cz/202409/t20240925_1995627.html)介绍三册22章、12项跨学科实践。课程概念按教材体系归纳，讲解、题目和图示原创，非教材扫描或全文转录。

化学方程式按本课教材规范书写；“是否配平”和“书写是否完整”分别判断。辨析题中的错误原稿保持原样，解析给出规范写法。

化学题型参考所提供练习资料和[广州2025化学命题说明](https://jyj.gz.gov.cn/yw/zsks/content/post_10341699.html)、[广州2024命题说明](https://jyj.gz.gov.cn/gkmlpt/content/9/9738/post_9738644.html)。新增题目为原创，不冒称中考原题。
