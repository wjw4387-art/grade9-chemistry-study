# 知学自主学习空间 · 九年级化学

[打开学习网站](https://grade9-chemistry-study.vercel.app/)

按人教版九年级化学新教材整理，上下册11单元、53小课、868道原创题。每课16–18题，包含单选、多选、填空、综合探究，按基础→提高→中考挑战排列。

## 使用

- 任选单元或搜索知识点，阅读定义、通俗讲解、图示与例题。
- 自由标记已掌握、暂时跳过；跳过不算已掌握。
- 做小课、单元、上册/下册或全年综合测试。逐题作答、答题卡跳转、自动保存草稿。
- 提交后查看解析，错题自动收集，重做答对后移出。
- 学习记录保存在当前浏览器；在“课程说明与学习记录”导出备份或导入到另一台设备。

课程空间为未来小学、初中、高中多学科扩展预留组织结构；当前只开放九年级化学。

## 部署

无需构建的静态网站。Vercel Framework Preset为Other，根目录 ./，构建与输出目录使用默认空值。GitHub main推送触发自动部署。

## 内容

讲解、示意图和练习题均原创整理，未上传扫描教材、原始试卷或学生照片。部分长课题拆成自主小课，保留教材对应关系。化学为人教版新教材，不冒称全国统一“部编版”或2026独立修订版。

填空题按规范答案集合匹配，不能理解任意同义长句。图示为教学模型，不代表仪器或微粒真实比例。
